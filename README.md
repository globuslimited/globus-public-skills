# GLOBUS public skills

Skills for operators. They are installed together:

```bash
npx skills add globuslimited/atlas-agent-skill
npx skills update
```

| Skill | Use |
|---|---|
| `atlas-agent-tool` | Read and change Atlas through the action catalog |
| `ads-manager` | Plan and run GLOBUS advertising. Lead quality and project money are read with `atlas-agent-tool` |

`atlas-agent-tool` is published from the Atlas package. `ads-manager` is maintained in this repository. Do not put tokens, private keys, or staff logins in either skill.
